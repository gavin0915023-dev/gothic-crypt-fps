# 暮影圣堂 · Gothic Crypt FPS

仿照纯前端原生 ESM + Three.js 程序化建模管线构建的哥特教堂与古墓园主题 3D 第一人称射击（FPS）人机匹配 Demo。**零构建工具、零 npm 依赖、零外部贴图/音频 CDN**，本地与 GitHub Pages 均可直接运行。

## 核心特性

- **哥特教堂与古墓三路立体地图（`arena.js` / `textures.js` / `sky.js`）**
  - 灵感源自《第五人格》红教堂与古墓园氛围：月夜深蓝天穹、满月浮云、破损红砖教堂中殿、自发光哥特彩绘玫瑰花窗、可沿石阶攀登的中央祭坛高台、翻倒教堂长椅、西侧雾林古墓园（石棺、穹顶墓室、凯尔特十字墓碑、枯枝老树与尖顶铁艺围栏）、东侧地下石棺回廊与二层高台、微光摇曳的铁艺路灯与远景古堡剪影。
  - 所有材质（青石地砖、红教堂风化砖墙、古墓灰岩、彩绘玻璃、深色橡木）与天穹环境贴图均在浏览器端程序化生成。
- **4v4 人机匹配 · 三档 AI 难度（`ai.js` / `bot-model.js`）**
  - **简单（见习守夜）**：反应 `520ms`、散布 `±8.5°`、主路稳步推进、5% 爆头倾向。
  - **普通（圣堂猎手）**：反应 `280ms`、散布 `±4.2°`、三路包抄、中距急停走位与掩体换弹、18% 爆头倾向。
  - **困难（古墓梦魇）**：反应 `145ms`、散布 `±1.9°`、积极抢占祭坛与回廊高台、高频急停跳枪与受击快速反拉枪、36% 爆头倾向。
  - 蓝队（玩家 + 3 名守夜 AI 队友）vs 红队（4 名猩红影徒 AI），率先达成 20 击杀或倒计时结束高分获胜。
- **3 把程序化 3D 第一人称武器 + 合成音效（`weapons.js` / `audio.js`）**
  - `[1]` **M4-圣堂**（突击步枪，全自动，右键红点开镜）
  - `[2]` **VX-9 影袭**（冲锋枪，高射速近战绕后）
  - `[3]` **AWP-猎月**（栓动狙击枪，右键 `2.6×` 高倍光学狙击镜，一枪爆头）
  - 含武器惯性晃动、步态起伏、后坐力上跳、动态枪口火光、弹道曳光、溅射火花与弹孔贴花；Web Audio 实时合成各枪械枪声、金属爆头提示音、命中反馈与换弹声。
- **FPS 移动与完整战术 HUD**
  - `WASD` 移动、`Shift` 疾跑动态广角、`Space` 重力跳跃（可跳上石棺/木箱/石阶）、`C`（切换）或按住 `Ctrl` 下蹲（降低视高与受击判定、收窄射击散布与后坐力）、`左键` 射击、`右键` 开镜、`R` 换弹、`1/2/3` 或滚轮切枪、`Tab` 战绩板、`Esc` 暂停/灵敏度/随时切换难度、`M` 静音；同时提供移动端触控操作。

## 本地运行与自动验证

```powershell
node server.mjs
```

打开 <http://127.0.0.1:4174> 即可游玩。

运行无头浏览器自动化验证（检查 WebGL 渲染、0 着色器错误、三档难度切换、移动跳跃、射击换弹、开镜与人机对战）：

```powershell
node verification/verify.mjs
```
